# 架构说明

## 系统架构

### AI 原生方案（当前）

```
┌─────────────────────────────────────────────────────────────┐
│                         用户对话                              │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    AI 实例（当前会话）                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │  理解需求   │→│  调用脚本   │→│   分析商品数据      │  │
│  │  提取参数   │  │  执行抓取   │  │   判断是否推荐      │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    spider.py（Playwright）                   │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │ 随机 UA     │  │ 模拟移动端  │  │  拦截 API 响应      │  │
│  │ 请求间隔    │  │ 登录状态    │  │  解析商品数据       │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                     闲鱼 (goofish.com)                       │
└─────────────────────────────────────────────────────────────┘
```

### 执行流程

```
1. 用户提出需求
   ↓
2. AI 解析关键词、预算、筛选条件
   ↓
3. AI 调用 spider.py --state state.json
   ↓
4. Spider 加载登录状态，模拟真实设备
   ↓
5. 随机延迟 5-10 秒，避免请求过快
   ↓
6. 访问搜索页，拦截 API 响应
   ↓
7. 解析商品数据，去重后返回 JSON
   ↓
8. AI 分析每个商品（价格、卖家、描述）
   ↓
9. AI 判断推荐/不推荐，生成报告
   ↓
10. 有新好货则立即通知用户
```

## 核心组件

### 1. Spider (spider.py)

**职责：** 闲鱼商品抓取

**主要功能：**
- **反反爬机制：**
  - 随机 User-Agent（5种设备）
  - 随机视口尺寸
  - Canvas 指纹混淆
  - 请求频率限制（5-10秒间隔）
- **登录状态：** 加载 Playwright storage_state
- **智能重试：** 指数退避策略，最多重试3次
- **代理支持：** HTTP/HTTPS/SOCKS5

**输出格式：**
```json
{
  "keyword": "iPhone 14 Pro",
  "count": 15,
  "items": [
    {
      "id": "123456789",
      "title": "商品标题",
      "price": 4800,
      "url": "https://www.goofish.com/item/123456789",
      "image": "...",
      "location": "上海",
      "seller": "卖家昵称",
      "publish_time": "2026-02-13 17:30",
      "wants": "6",
      "tags": ["包邮", "验货宝"]
    }
  ]
}
```

### 2. Task Manager (task_manager.py)

**职责：** 监控任务管理

**功能：**
- 创建/停止/删除任务
- JSON 文件存储（无需数据库）
- 命令行接口

**数据格式：**
```json
{
  "id": "task_20260213_173146",
  "keyword": "Surface Laptop",
  "max_price": 6000,
  "status": "running",
  "created_at": "2026-02-13T17:31:46",
  "last_run": "2026-02-13T17:35:00",
  "results_count": 30
}
```

### 3. Login State Creator (create_state.py)

**职责：** 生成 Playwright 可用的登录状态

**使用场景：**
- 从浏览器 Cookie 快速生成 state.json
- 手动复制 Cookie 时使用

## 数据流

### 单次查询完整流程

```
用户: "帮我找 MacBook Air，预算6000"
  ↓
AI: 解析参数
  - keyword: "MacBook Air"
  - max_price: 6000
  ↓
AI: 调用 spider.py --keyword "MacBook Air" --max-price 6000 --state state.json
  ↓
Spider:
  1. 加载登录状态
  2. 随机选择 UA 和视口
  3. 等待 5-10 秒（频率限制）
  4. 启动浏览器，访问搜索页
  5. 拦截 API 响应
  6. 解析商品数据
  7. 返回 JSON
  ↓
AI: 分析商品
  - 价格是否合理
  - 卖家是否可信
  - 商品是否值得买
  ↓
AI: 生成报告
  ✅ 推荐商品
  ❌ 不推荐商品
  🔍 需要确认商品
  ↓
用户: 查看结果，点击链接购买
```

### 定时监控流程

```
Cron: 每2小时触发
  ↓
AI: 检查所有运行中的任务
  ↓
AI: 对每个任务调用 spider.py
  ↓
AI: 对比新结果与已通知商品
  ↓
AI: 有新好货？→ 推送通知
```

## 安全与风控

### 已实现的防护措施

1. **请求频率控制**
   - 最小间隔 5 秒
   - 最大间隔 10 秒
   - 随机延迟，模拟人类

2. **设备指纹混淆**
   - 随机 User-Agent
   - 随机屏幕尺寸
   - Canvas 噪声注入
   - 随机地理位置（上海区域）

3. **失败重试**
   - 指数退避（5s, 10s, 15s）
   - 最大重试 3 次
   - 错误日志记录

4. **代理支持**
   - HTTP/HTTPS/SOCKS5
   - 认证支持
   - 便于 IP 轮换

### 建议的安全配置

- **抓取频率**：每 30 分钟以上一次
- **关键词数量**：同时监控 3-5 个
- **代理使用**：强烈建议使用
- **登录状态**：每周更新一次

## 优缺点分析

### 优点

1. **极简部署**：无需数据库、Web UI、Docker
2. **AI 直接控制**：无需外部 API，分析质量高
3. **文本交互**：自然语言对话，门槛低
4. **灵活扩展**：可随时调整分析逻辑
5. **隐私保护**：数据不发送到外部服务器

### 缺点

1. **需要登录状态**：必须定期更新
2. **风控风险**：频繁抓取可能被封
3. **依赖代理**：大规模使用需要代理池
4. **响应延迟**：每次抓取需要 10-30 秒

## 性能优化建议

1. **批量处理**：定时任务时批量检查多个关键词
2. **结果缓存**：已分析的商品缓存 24 小时
3. **增量更新**：只抓取最近 1 小时的商品
4. **异步队列**：使用消息队列处理大量任务

## 扩展方向

1. **多账号轮换**：支持多个 state.json 自动切换
2. **图片识别**：使用 OCR 提取商品图片信息
3. **价格追踪**：记录历史价格，判断趋势
4. **智能推荐**：基于用户偏好学习推荐算法
